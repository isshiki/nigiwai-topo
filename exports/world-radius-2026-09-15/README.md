# 世界共通の参照点密度データ

全業種・Gaussian σ200mの密度の面から、各参照点の直線距離800m以内の最大値を求めたデータ。地形図と駅Tier表は同じ結果を使う。

22,667参照点を計算し、このCSVには地図表示対象の800件/km²以上の13,235参照点を収録する。最大点が同じでも、参照IDが違えば別行にする。駅や都市の独占商圏ではない。世界の全駅の網羅を保証しない。

列：参照ID、地名、登録密度（件/km²）、最大点の緯度経度、参照点の緯度経度、半径（m）。WGS84 / EPSG:4326。UTF-8 BOM。表示名だけで集計せず参照IDを使う。CSVは地図の表示範囲や衝突回避による省略に左右されない。

Foursquare OS Places 2026-09-15 / Apache 2.0。閉店判明分除外、位置品質の計算保留5,446件。地名：GeoNames CC BY 4.0、国土数値情報 N02 CC BY 4.0、OpenStreetMap ODbL等。日本語化はベストエフォート。位置・営業状況・地名の正確さや国・地域間の比較可能性を保証しない。

旧 `exports/world-2026-09-15` は名前付き局所最大点を収録した過去の方式で、このCSVとは対象が異なる。
