# 駅のにぎわいTier表：ローカル試作（2026-10-13）

公開サイトへはまだ反映していない。ローカルサーバーの`/station-tier.html?pref=13`で東京、`?pref=13&city=練馬区`で練馬区、`?pref=`で全国を開ける。

## 実装したこと

- SS / S / A / B / C / Dの6行にカードを自動配置。駅記号と駅名、県・市区町村を表示。ドラッグ操作なし。
- 全国・47都道府県・市区町村、路線、駅名で絞り込む。Tierは全国基準から変更しない。
- 各Tierの件数と対象駅数を表示。条件に合うカードは初めからすべて表示。各Tier内は得点順で、件数を明記する。追加表示ボタンや30件の打切りはない。画面外カードの描画はCSS content-visibilityで軽減する。
- カード詳細に得点・割当登録件数・計算条件・判定基準と地形図へのリンク。地形図は座標とズームで駅周辺を開く。
- 地形図から同じ都道府県のTier表へ移動。市区町村はTier表で指定する。

## データと試作条件

- 元の全国9,046のN02駅グループに加え、同名・同一市区町村で全メンバー間500m以内の14組を統合し、9,032カード。東京都654、練馬区19。異名乗換駅は未統合。
- 駅は代表位置で県・市区町村へ分類。旧東京都境界内656という調査件数とは定義が異なる。
- 同名の遠隔駅はIDで区別。カード・詳細に県と市区町村を表示。会社・路線は詳細と路線フィルターで区別できる。
- 取得済みFoursquareの2026-09-15 active.parquetからJP登録、経度122〜154、緯度20〜46を抽出。閉店判明分除外。既存位置品質保留5,446IDも照合したが、日本抽出内の該当は0。
- 各POIは元の駅代表点から800m以内の最寄り1駅グループに割当。同名近接の統合後は所属する1カードへ得点・件数を集約し、所属路線もすべて保持。統合した座標の平均点から距離を測り直す方式ではない。球面KDTreeの近隣3候補をWGS84測地線距離で比較。
- 得点は`Σ exp(-0.5 × (距離m / 400)^2)`。単位は距離加重の登録件数で、地形図の密度（件/km²）ではない。
- 日本抽出4,532,704登録、駅へ割当2,507,837、800m外2,024,867。全駅の割当件数合計が一致。
- SS / S / A / B / Cは全国得点の99 / 95 / 80 / 50 / 20パーセンタイル以上。残りと登録0はD。同点を境界で分けない。フィルターで境界を再計算しない。
- Tier別全国件数：SS91、S361、A1,355、B2,709、C2,709、D1,807。

## 再生成・検証

```powershell
.venv\Scripts\python.exe scripts/build_station_tiers.py
.venv\Scripts\python.exe -m unittest tests.test_station_tier_data
node --check web/station-tier.js
```

生成にはGit管理外のPOI、全国stations.json／regions.json、公式N02原本が必要。原本は`data/raw/station-tier/N02-25_GML.zip`。既存取得manifestのSHA256と一致を確認して使用。スクリプトは原本をネット取得せず、資格情報も使わない。

成果物は`web/station-tier-data.json`。集計検証記録は`data/validation/station-tier-build.json`。パッケージにTier画面・スタイル・スクリプト・集計済みJSONを追加し、リンク検査も対象にした。

## 確認結果と残ること

- 元駅IDの完全な分割と全国参照表の一致、路線・地域情報、割当件数の収支、重みの値域、全国Tier再計算一致に加え、池袋1カード7路線、離れた同名・異名の維持、連鎖的な過剰統合の防止を確認する5テスト成功。
- ブラウザで練馬区19件、西武池袋線8件、練馬Sの詳細（1,387.723点・1,763登録）、駅周辺への地図移動、390px幅のレイアウトを確認。
- 既存世界地図の日本地方・県・韓国・表示範囲ランキング回帰検証に成功。
- 集計距離500/800/1000m、固定円と最近傍、異名乗換駅統合による順位の感度比較は未実施。全国集計済みでも試作であり、条件は最適値と証明していない。
- 歩行経路・川・出入口を考慮せず、位置・営業・重複・登録偏りを全件検証していない。0登録を実際の店舗ゼロとはしない。

## 池袋・全件表示・路線検索の修正

- 池袋の副都心線側と他路線側の2グループを統合し、7路線・1カードにした。得点と全国Tier境界を再計算。
- 同名近接の自動統合500mは試作ルールで、公式の乗換関係を全件確認した意味ではない。同名でも離れた駅は維持し、500m以内の連鎖だけで遠くまでまとめない。
- 「さらに表示」を廃止。全国9,032カード／東京654カードをすべて生成する実画面スクリプトの検証に成功。
- 路線は文字の部分一致検索＋候補表示へ変更。「副都心線」「池袋線」や会社名で絞れる。URLにも検索条件を保存。
- ブラウザで「池袋」を検索すると池袋・東池袋・北池袋・東池袋四丁目の4駅（部分一致）。さらに「副都心線」で1駅になり、池袋自身は1カードであることを確認。
- 自動画面検証：`node tests/station_tier_frontend_check.cjs`。
