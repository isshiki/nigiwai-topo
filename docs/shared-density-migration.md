# 地形図とTier表の共通化作業

世界共通の参照座標照合・再計算・代表点索引と全国Tier表の生成を完了した共通化設計。段彩・等高線は同じ原データと200m平滑化による密度の面を維持し、名称付きの代表点と得点を共通結果へ切り替える。

## 共通の評価方法

- 元データ、閉店判明分の除外、位置品質の計算保留、200mの平滑化、共通格子を地形図とTier表で共有する。
- 駅・都市・地区などの参照点から、直線距離800m以内の格子の最大登録密度を求める。
- 地図の数値、ランキング、Tier表、詳細リンクは同じ結果レコードの値と座標を使う。表示名から再照合しない。
- 等高線と段彩は既存と同じ密度の面を描く。半径内の最大点が局所的な山頂とは限らないため、新しい代表点を実際の山頂と説明しない。
- 日本のみ例外的に旧値を使うことはしない。新しい共通方式に伴う数値・順位の変更は両画面で一致させる。
- 同じ最大点を共有する近隣駅はあり得る。参照IDと最大点IDを区別し、地図の重なりを処理する。駅別の比較はそれぞれの800m範囲で行う。
- 名称の変更・翻訳で得点を変えない。同名の別地域を文字列だけで統合しない。
- 日本のTierは全国9,032駅の共通基準を維持する。海外の駅・都市と日本の駅の収録網の完全性が同じだとは説明しない。

## 進める順序

1. 既存の全世界の表示対象について参照座標を照合する。
2. 原POIを空間分割し、同一半径の最大密度を世界共通で計算する。
3. 計算結果から地図の代表点・ランキングと全国Tierデータを生成する。
4. 御茶ノ水、両国、提示された20地点、海外の複数地域、日付変更線・高緯度を検証する。
5. 全世界CSV、総武線・大阪中央線カバー、記事メモ、READMEとAboutを更新する。
6. 配信データと画面を一緒に切り替え、公開サイトで同一ID・座標・値を確認する。

## ローカルの処理

`node scripts/audit_shared_density_references.cjs` が既存の表示名解決と取得済み参照資料を使って、`data/shared-density/references.json` に参照座標を列挙する。追加のGeoNames参照は取得済み国別資料から `data/shared-density/extra-geonames.json` に照合結果を保存する。

`python scripts/build_shared_world_density.py` が原POIを空間分割し、`data/shared-density/maxima.json` に結果を逐次保存する。中断後に再実行できる。生成物はGit管理外とし、この処理自体は公開ファイルを書き換えない。

参照資料の照合では、旧表示対象23,187峰に対して日本の9,032駅を含む22,667参照点を確認し、参照座標不明は0件。全参照点の計算を完了し、800件/km²以上の13,235点を配信対象とした。これは新方式で800件/km²以上になる地点数とは異なる。

配信：`https://re.masahiko.info/nigiwai-topo/world/2026-09-15-radius2/`。全128索引JSONの内容をCDNから照合済み。全国9,032駅の値・最大点座標と、地図生成元レコードの一致を検証した。
