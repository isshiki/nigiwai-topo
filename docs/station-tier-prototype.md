# 駅のにぎわいTier表：現在のローカル実装（2026-10-13）

公開対象： https://isshiki.github.io/nigiwai-topo/station-tier.html?pref= 。東京：`http://127.0.0.1:8820/station-tier.html?pref=13`、全国：`?pref=`。

## 現在の指標

- 地形図の世界v6・全業種・σ200mの、駅に対応する峰の最大登録密度（件/km²）を使う。旧方式の距離加重POI件数は現在の得点に使わない。
- N02参照駅IDを元駅IDへ照合。同名・同一市区町村、全メンバー間500m以内の統合駅では、メンバーに対応する峰の最大値を使う。密度を足し合わせない。
- 全国9,032駅（元9,046グループ）、47都道府県。対応する峰がある5,406駅と、「峰なし」3,626駅を収録。峰なしは0密度ではなく未判定の別枠。
- 5,406駅の密度分布の99/95/80/50/20パーセンタイルをSS/S/A/B/C境界に使い、残りをDとする。同点は分けない。絞り込んでも全国境界は変わらない。
- 800以上の峰に対応する駅は937。800未満の計算済み峰もTier表に含むが、地形図では▲・段彩を表示しない。この違いは詳細と説明欄へ明記。
- 池袋15,952、渋谷20,383、銀座22,414件/km²は配信地図と一致。新宿そのものなど、近隣駅へ峰名が付いている駅は「峰なし」になり得る。

## 表示と操作

- SS〜Dと別枠の「峰なし」。各Tier内は密度順、丸める前の値で並べる。同密度は駅ID順。条件に合う全件を初めから表示し、追加表示ボタンは置かない。
- 都道府県・市区町村、路線の部分一致検索、駅名検索。市区町村は駅代表位置の既存地域属性を使う。
- カードは実SVG電車アイコン、駅名、地域、整数の密度。同名駅が残る場合は事業者・路線の短い補足を付ける。詳細には全路線。
- 元の四角は文字記号「▣」だった。現在は自作のtrain-icon.svgを使用。
- 詳細に密度の意味、Tier理由、データ日付、下限未満の注意。SSに上位Tierという説明は付けない。表示は整数で、内部の値は保持。
- 地図リンクは対応峰の座標とズームを指定する。峰なしは駅周辺を開く。
- 地図の左パネル末尾に目立つTier表ボタン。CSVリンクは地図から除き、記事とリポジトリの説明に残す。
- ヘッダーは「あなたの駅は、何Tier？」。注意・条件は折りたたみ説明へまとめる。

## 再生成

```powershell
.venv\Scripts\python.exe scripts/build_station_tiers.py
# 駅の統合・路線データが既にある場合、峰との照合だけを再実行できる
node scripts/match_station_tier_peaks.cjs
python scripts/make_station_tier_covers.py
```

build_station_tiers.pyはN02原本と全国駅参照から駅台帳を生成し、match_station_tier_peaks.cjsで地図の峰へ照合する。原POIの再集計は不要。N02原本・全国駅参照・世界v6の分割峰JSONはGit除外のローカルデータ。ピーク照合はネット取得も資格情報も不要。世界の地形は再生成しない。

match_station_tier_peaks.cjsは地図と同じ名称解決関数と保留判定を使い、IDで照合する。元密度を変更せず、ピーク位置と名称・参照IDを保持。成果物はweb/station-tier-data.json。検証記録はdata/validation/station-tier-map-density.json。

## 確認と限界

- 元駅IDを漏れなく一度だけ収録、池袋1カード7路線、離れた同名・異名の維持、過剰な連鎖統合の防止を検査。
- カード全件、部分路線検索、SVG・整数表示・SS文言・同名駅補足、峰なし件数を実画面スクリプトで検証。800以上の密度・峰座標は公開CSVと照合。
- 390pxブラウザ幅で全国表示のレイアウトを確認。実機のCPU・通信・スクロール速度の測定とは区別する。表示全件を維持し、CSS content-visibilityで画面外の描画を軽減。
- 駅そのものの密度ではない。峰名の割当、駅統合、登録偏り、位置・営業情報の誤りで結果が変わる。人出・人気・売上・駅の優劣ではない。
- 異名の乗換駅は未統合。最新の全実在駅を独自に網羅確認した意味ではない。

## 原宿の表記とTier見出しの説明

原宿（003828）と明治神宮前（003844）は異名のため現在は別カード。原宿は峰なし、明治神宮前には11,936件/km²の峰が対応する。峰は駅そのものではない。東京メトロの公式表記に合わせ、地図・カードでは「明治神宮前〈原宿〉」と表示し、「原宿」で検索できるようにした。駅ID、統合対象、密度は変えていない。

公式参照：https://www.tokyometro.jp/station/meiji-jingumae/index.html

SS〜Dと峰なしの見出しをボタンにし、クリック・タップ・キーボードで説明を開ける。ホバーでも全国割合のヒントを表示。対象は対応する峰がある5,406駅で、割合、密度範囲、全国該当数、同点・丸めの留保を表示する。峰なしは全国3,626駅の未判定と説明し、0密度とは扱わない。
