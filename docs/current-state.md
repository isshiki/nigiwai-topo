# 現在の仕様（2026-10-13）

## 表示と評価

- 地形図：https://isshiki.github.io/nigiwai-topo/
- 駅Tier表：https://isshiki.github.io/nigiwai-topo/station-tier.html
- 全業種・Gaussian σ200m・世界共通格子の登録密度の面を両方で共有する。
- 参照点から直線距離800m以内の最大密度を世界共通で計算。名前が割り当てられた旧峰の有無は条件にしない。
- 世界22,667参照点を計算し、800件/km²以上の13,235点を地図表示対象とする。世界の全駅を網羅した意味ではない。
- 日本の全国9,032駅は同じ共通結果からTierデータを生成。全駅が計算対象となり「峰なし」は廃止。
- 近隣の参照点が同じ最大密度地点を共有する場合がある。地図の衝突回避でラベルを省略する場合も、計算値は変わらない。
- 代表点は●。実在の山頂や駅の入口ではなく、800m範囲内の最大密度の位置を示す。
- 地図の表示範囲に応じて、同じ参照地名は最高密度の1件を表示し上位20件をランキングする。同名の別地域には地域等を補足する。
- 駅名検索は実際の参照駅位置へ青いマーカーを出す。「お茶の水」でも「御茶ノ水」を検索できる。
- 地域選択、現在地、段々3D、スマホの操作パネル開閉、読み込み表示、Googleマップ／経路リンクを維持。
- 背景はOpenStreetMap。背景文字は翻訳しない。名前・位置・営業状況の正確さは保証しない。
