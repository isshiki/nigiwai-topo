# 現在の公開仕様（2026-10-12）

この文書とREADMEを現在状態の入口とする。試作・調査記録に残る「未公開」「進行中」や旧版の件数は、その記録時点の状態。

## 公開・操作

- 公開：https://isshiki.github.io/nigiwai-topo/ 。GitHub Pagesの公開成功と公開画面の地名・ランキングを確認済み。
- 密度データはFoursquare OS Places 2026-09-15。全業種・σ200m・800件/km²以上を固定表示。業種・データ源・幅・下限の選択はない。
- 世界・大陸・国、日本の地方・都道府県へ移動。地域選択は世界共通データ上の表示先を切り替える。
- 表示範囲の異なる参照地名の上位20件。同じ参照地名の峰は最高密度の1件を代表にし、別地域の同名地は地域を併記。
- 段々3D、表示中の山名検索、現在地、スマホの操作パネル開閉、読み込み状態に対応。
- ▲のポップアップは名称・登録密度・簡潔な注意とGoogleマップ／経路リンク。出典ID・距離・詳細な命名根拠はデータや調査記録に保持し、一般読者向けポップアップには列挙しない。
- 背景はOSMタイル。山名は日本語を優先するが、背景文字は翻訳しない。

## データ・名称の状態

- 接続先：`https://re.masahiko.info/nigiwai-topo/world/2026-09-15-v6/`（web/config.js）。
- 計算入力101,729,089件、峰319,883個。位置品質の計算保留5,446件。全件の誤位置が確定した意味ではない。
- 配信7,052ファイル、394,378,869 bytes。公開画面用のHTML・辞書などは別のPagesパッケージ。
- 密度800以上の23,187峰に名称未登録は0件。下限未満の4,431峰（最大798）は追加名称調査を終了。正しい読み・区域・位置を全件保証する結果ではない。
- 「付近」「駅付近」は山名に使わない。日本はN02、韓国は取得済みOSM駅、その他は都市・地区など。未取得の駅網や翻訳・音写の誤りは残り得る。

## 配信と検証の根拠

- `.github/workflows/pages.yml`：mainのプッシュで画面をパッケージ・検証・公開。地図の再取得／再計算はしない。
- `scripts/package_pages.py --config web/config.js`を使用すると設定ファイルがコピーされる。必須の`--data-url`はこのモードでは接続先を上書きしない。
- 大容量データは非公開S3＋CloudFront。原本・生成データ・認証情報はGit管理外。
- 公開時：Python64テスト成功。全319,883峰の表示名検査、238地域×3下限＝714条件で索引の結果と全件走査が一致。3下限は内部検証条件で、公開UIの選択肢ではない。
- `data/validation/pages-world-tests.log`：禁止接尾辞0、外国語の残る命名済み峰0、800以上の座標のみ表示0。
- `data/validation/world-v6-published.json`：全ファイルとサイズ、Range・CORS検証成功。
- 公開HTTPでトップ・About・JS・CSSが200、CloudFront manifestが200とCORS許可を確認済み。
- 自動検査の成功は内容の全件正確性や将来の配信速度・可用性の保証ではない。
