# 世界の山の表示名（現在の仕様）

- 山名は近くの駅・都市・地区などを参考にした名称。実在の山、街の中心、厳密な行政区域の所属を示さない。
- 「付近」「駅付近」は使用しない。日本はN02、韓国は取得済みOSM駅、その他は都市・地区など。世界の全駅は未取得。
- 出典ID・原名・位置・国を照合して辞書を接続。登録日本語名と公開資料を優先し、不足分には言語モデルの音写候補と編集表記を採用。モデルは場所の同定の証拠ではない。
- 韓国はカタカナ、中国・台湾は原語漢字別名や確認資料を利用して日本語向けの表記に整える。すべての字形・発音・日本語名を公的に確認した意味ではない。
- 推定表記には「（推定）」を表示。背景地図の文字は翻訳しない。
- 同じ参照地名は表示範囲で密度が最大の峰を代表1件にする。別地域の同名地は国・州・県などを添える。密度の面をまとめたり、街の内部の山を消したりはしない。
- ランキングは表示範囲の代表地名上位20件。元データの峰数や都市の総登録数の順位とは異なる。

## 現在の検証結果

- 世界v6の319,883峰を検査。禁止接尾辞0、命名済み峰に外国語文字が残る表示名0。
- 800以上の23,187峰で名称未登録は0。下限未満4,431峰（最高798）は追加調査を終了。
- 世界・大陸・国・日本の地方と県の238範囲×内部検証用3下限＝714条件で、索引の結果が全件走査と一致。公開下限は800固定。
- 日本語文字だけであることや未登録0は、名前・読み・位置が正しい保証ではない。
- 原名・距離・参照ID・採用根拠はデータと調査記録に保持。現在のポップアップは一般読者向けの名称・密度・注意・Googleマップリンクを表示し、これらの詳細は列挙しない。

## 再現・参照

```powershell
$env:NIGIWAI_WORLD_ROOT='data/distribution/foursquare-world-v6'
$env:NIGIWAI_STRICT_NAMES='1'
$env:NIGIWAI_VERIFY_ALL_REGIONS='1'
node tests/world_display_names_check.cjs
node tests/distinct_peak_index_check.cjs
```

生成辞書は`web/world-display-names.js`など。確定表記・推定・採用根拠の編集記録はdocsのJSON／TSVに保持する。辞書生成スクリプトの実行は既存調査成果を変更するため、単なる検証では不要。
