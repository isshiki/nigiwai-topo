# 駅のにぎわいTier表：記事執筆用メモ

2026-10-13の世界共通方式への更新。地形図とTier表を同じ参照点・同じ密度の評価方法で作成。

- タイトル案：駅周辺のにぎわいでTier表を作ってみた
- サービス名：駅のにぎわいTier表
- 公開URL：https://isshiki.github.io/nigiwai-topo/station-tier.html
- 地形図：https://isshiki.github.io/nigiwai-topo/
- 「あなたの駅は何Tier？」という遊びとして紹介する。
- 全国9,032駅、47都道府県。初期表示は東京。全国・市区町村・路線・駅名で絞り込める。
- 全駅で代表位置から直線距離800m以内の最大登録密度を使う。駅の名前が山に付いていないことを理由に、評価対象から外さない。
- 地形図とTier表は同じ結果から生成する。世界の駅・街・地区にも同じ半径800mを適用する。
- 密度の面は全業種・ならす広さ200m。半径800mは評価範囲、200mは密度をならす条件で別の数値。
- 密度は件/km²。店舗数そのもの、実際の人出、人気、売上、駅の優劣を示すものではない。
- 近隣駅は同じ最大密度地点を共有する場合がある。各駅の独占商圏や徒歩圏ではない。
- 同名・同一市区町村で全メンバー間500m以内の駅は統合。異名の乗換駅は別扱い。
- SS/S/A/B/C/Dは全国9,032駅の99/95/80/50/20パーセンタイルを境界にする。同点は分けず、絞り込んでもTierは変えない。
- 地図は800件/km²未満の代表点を表示しないが、Tier表では全駅を評価する。表示されないことは店舗ゼロではない。
- 世界の参照点22,667地点を計算し、800件/km²以上の13,235地点を地図表示対象にした。世界の全駅を網羅した意味ではない。
- 元データ：Foursquare OS Places、2026-09-15。閉店判明分除外。位置に疑義がある5,446登録は計算保留。正常な登録が含まれる可能性もある。
- 地名は取得済み参照資料と日本語辞書・音写を使用。公的な表記として全件確認した意味ではない。
- 地域・観光地・国ごとの登録偏り、位置の誤り、未登録や閉店情報の漏れがある。
- 800mや200mが最適だと実証したものではない。別条件での感度分析・経済センサスとの比較は今後の課題。
- カバー：docs/assets/station-tier/cover-sobu.png（1600×900、総武線46駅）。SS1/S9/A12/B12/C8/D4。御茶ノ水・両国も評価対象。
- N02の総武線区分で、中央・総武線各駅停車だけを取り出したものではない。
- 大阪メトロ中央線15駅カバーも更新。SS0/S2/A6/B6/C0/D1。
- CSVは記事からGitHubへ案内する。地図の操作パネルにダウンロードリンクを置かない。
- 新しいCSVは参照ID、地名、登録密度、最大点座標、参照点座標、半径を含む。同名をIDで区別できる。旧「山の頂」のCSVとは対象が異なる。
