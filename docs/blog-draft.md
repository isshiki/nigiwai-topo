# にぎわいの地形図 — 記事下書き

お店と施設の登録密度を、山に見立てた地図を作りました。店がまとまる場所は山に、登録がまばらな場所は平地のように見えます。段彩と等高線を重ね、段々の3Dでも眺められます。

## 描いているもの

Foursquare OS Placesの2026年9月15日版を固定して使いました。密度の単位は件/km²です。これは登録された施設の多さであり、人出、売上、床面積、実際の標高ではありません。登録の少ない地域を「にぎわいがない」と読むこともできません。

日本版では業種とならす広さを切り替えられます。世界版はまず「すべて・σ200m」を提供します。初期の表示下限800件/km²は表示上の選択であり、それより下を店舗ゼロとみなすものではありません。

## 作り方

POIを格子に集め、ガウスカーネルでならして密度を計算しました。日本版は100m格子と正積投影、世界版は緯度に応じて距離・面積を近似補正する約0.0009度格子です。区画の周囲に余白を取り、国・県の境界で単純に店を切り捨てないようにしています。遠景は概観、拡大時はPMTilesの詳細形状を取得します。

▲は局所最大点です。地形の突出度で独立した山を選ぶ処理はまだありません。ランキングは現在の地図表示範囲にある峰の密度上位20件です。都市全体の総合順位を意味しません。

## 名前と位置を確かめる

峰名には駅や近隣地名を使います。日本語の登録名に加え、原語からの音写・漢字表記もあるため、根拠と元の名称を保持しました。曖昧だった深圳の参照地名は、周辺POIの住所と公的所在地を照合し、6峰を海上世界・太子湾・印力中心・竹子林・沙井の京基百納広場・前海桂湾の万象前海という参照名に変更しました。行政区域への厳密な包含判定ではありません。

位置品質の疑わしい13集中群は元IDと座標を調べ、5,436件を暫定的に計算から保留して地形を再生成しました。全件の誤位置が証明された意味ではなく、正常な登録が混じる可能性もあります。原本と保留規則を残して戻せるようにしました。

## 何がまだ言えないか

地域・国・観光地による登録の偏り、閉店情報の不足、重複や誤位置があります。世界の名前をすべて日本語化したわけでもありません。ならす広さで峰の数と順位がどれだけ変わるか、経済センサスとどこまで一致するかは追加検証が必要です。したがって現段階では、登録密度の分布を眺める実験として紹介します。

公開前にアプリURL、画面画像、感度確認・経済センサス比較の実施状況を追記します。結果が未完成の項目を検証済みとして書かない方針です。
