# 「にぎわいの地形図」記事の執筆用メモ

完成原稿ではなく、一般読者向け記事の材料。

## 冒頭

- お店と施設の登録密度を山に見立てた世界地図。
- 街のお店・施設の集まりを眺め、商圏を調べる入口にも使える。
- 実際の人出・人気・売上、商圏の境界、購買力を測定するものではない。
- 遊びとして眺め、訪問や分析では公式情報・人口・交通など別資料と合わせる。
- 地図：https://isshiki.github.io/nigiwai-topo/
- 駅Tier表：https://isshiki.github.io/nigiwai-topo/station-tier.html

## 何を描いたか

- Foursquare OS Places 2026-09-15の登録。全業種、閉店が判明している登録を除外。
- 登録が集まるほど緑→茶色の高い山に見える。等高線と段々3Dも使える。
- 高さは登録密度（件/km²）。店舗の大きさや実際の標高ではない。
- 800件/km²未満は透明。店舗がない意味ではない。
- 名前付きの●は駅・街などの参照点から半径800m以内で最も登録密度が高い地点。世界全体と駅Tier表で同じ値を使う。
- ●は局所的な山頂や駅入口そのものとは限らない。背景に印刷された三角などの記号とも区別する。
- 表示範囲の地名トップ20は移動・拡大で更新。項目からその地点へ移動する。
- 名前検索では駅の参照位置を青いマーカーで示す。
- Googleマップ・経路リンクは最大密度地点を開く。

## 作り方

- 公開POIを取得し、閉店判明分を除き、位置品質に疑義がある一部の登録を計算保留にする。
- 全業種・200mのGaussianカーネルで密度をならす。世界共通の格子と緯度に応じた実距離・面積を使う。
- 周囲を含めて区画ごとに計算し、密度の面から段彩と等高線を作る。
- 駅・都市・地区などの参照座標を照合し、全地点で直線距離800m以内の最大密度を求める。
- 200mは平滑化、800mは評価範囲で、役割が異なる。
- 世界22,667参照点を評価し、800件/km²以上の13,235点を表示対象にした。世界の全駅を網羅した意味ではない。
- 地形図と全国Tier表は同じ計算結果から生成し、名前だけで得点を照合しない。
- 密度の面はPMTiles、代表点は表示範囲に応じた索引で外部配信。画面はGitHub Pages、データはS3/CloudFront。

## データ・地名の限界

- 登録の多さであり、営業中の実店舗数を一件ずつ確かめたものではない。
- 地域や観光地、国によって登録の偏りがある。位置・住所・閉店情報の誤りが残る。
- 計算入力101,729,089登録。位置品質の計算保留5,446件には、正常な登録が含まれる可能性もある。
- 名前はN02・OSM・GeoNamesなどから参照し、日本語辞書・音写と編集表記を使う。
- 地名の読み・表記や中心座標の正確さは保証しない。背景文字は現地の表記。
- 参照点の収録は完全ではない。半径800mは徒歩距離でも独占商圏でもない。
- 近隣の駅や街が同じ最大密度地点を共有することがある。
- 200m・800mが最適と実証したものではない。感度分析と経済センサス比較は今後の課題。

## 世界CSV

- [参照点密度CSV（13,235地点）](https://github.com/isshiki/nigiwai-topo/raw/refs/heads/main/exports/world-radius-2026-09-15/world-reference-density.csv)をGitHubから直接配布。
- 列は参照ID、地名、登録密度、最大点座標、参照点座標、半径。分析では名前だけでなくIDを使う。
- 同じ最大点を共有する参照地名は別行。画面の衝突回避や表示範囲による省略はCSVに適用しない。
- 地図の表示下限800以上の条件に限定。区域内のPOI登録件数を数えたCSVではない。
- 旧23,187峰・14,563地名代表のCSVは以前の局所最大点方式の記録で、現在の代表点とは対象が異なる。
- 商圏分析の入口にはなるが、売上予測や出店判断の根拠として単独では使わない。

## 駅Tier表・カバー

- 全国9,032駅に同じ800m範囲を適用。名前付き峰がない駅も評価し、「峰なし」は廃止。
- SS〜Dは全国基準。地域・路線を絞っても基準は変わらない。
- 御茶ノ水9,776件/km²/S、両国4,353件/km²/A。池袋15,952件/km²/SS。
- 総武線46駅カバーを更新：SS1/S9/A12/B12/C8/D4。N02の総武線区分で、中央・総武線各駅停車だけではない。
