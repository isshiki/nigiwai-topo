# 駅のにぎわいTier表：実現性と試作案（未実装）

- サービス名：駅のにぎわいTier表
- 記事タイトル：駅周辺のにぎわいでTier表を作ってみた
- 主画面はSS / S / A / B / C / Dの6行のTier表。カードは駅名＋共通の駅記号。自動配置、検索、地域・路線絞り込み、詳細表示。ドラッグ＆ドロップなし。
- 地図による縄張りの表示や色分けは不要。既存の地形図へのリンクは詳細の補助機能。

## 実現性・確認済みの資産

- 日本全国版のstations.jsonに9,046駅グループ。ID、駅名、座標、県コード、市区町村を保持。
- 加工済み駅一覧には路線名・運営会社がない。prepare_names.pyはグループ化時に落としている。
- 国土数値情報N02原本は駅名・路線名・運営会社・駅コード・グループコードを提供する。既存コピーを確認し、なければ公式原本を取得して補完できる。
- 根拠：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html
- N02グループは同名・近接駅をまとめるもので、異名の乗換駅をすべて統合するものではない。駅名文字列をIDとして使わない。
- data/world-build/active.parquetは存在。取得済みの原POIを集計に再利用できるが、既存の位置品質保留IDを反映した入力にする必要がある。
- 公開CSVの23,187峰／14,563地名代表は駅の一覧ではない。低密度駅・峰のない駅が欠けるので、そのまま全駅のスコアに使えない。
- まず日本を対象とする。世界の駅データは網羅しておらず、日本の全駅対応から世界へそのまま広げる構成ではない。

## 推奨する集計の候補

1. 駅単位を固定：N02駅グループIDを基本とし、路線・会社は配列として全所属を保持。異名乗換駅は別カードを初期仕様とし、統合が必要なケースを比較する。
2. POIを最近傍の駅に割り当てる。候補の最大距離は500m／800m／1kmを比較。距離上限を超えるPOIは駅のものとして集計しない。巨大な郊外の縄張りを無制限に作らない。
3. メイン候補は割当POIの距離加重件数。近いほど重くする方式と単純件数を比較し、採用した式・距離・単位を公開する。参考として単純件数、飲食・買い物などの内訳も保持する。
4. 隣駅との重複集計を避けるため1 POIは1駅に割り当てる。固定円の単純集計も比較し、隣駅や乗換駅に分割する影響を確認。川・線路・出入口・歩行経路を反映しない直線距離の近似と明記。
5. 得点は登録の集積を表す。乗降客数・人気・売上・駅の優劣とはしない。現行地図の200m密度や800下限をこの集計の条件へ自動流用しない。

## Tierの決め方

- 初期候補：全国分布の上位1%をSS、次の4%をS、次の15%をA、次の30%をB、次の30%をC、残りをD。割合は試作候補で、確定仕様ではない。
- 同点をTier境界で分断しない。同点が多い場合は予定の割合からずれる。登録0をどのTierに置くかは実データの分布を見て決める。
- データ版ごとに全国の得点境界を保存。地域・路線で絞ってもTierは変えない。フィルタ内の順位を表示する場合は全国Tierと分ける。
- 0件を自動的に実際のにぎわいがないとみなさない。集計不能・資料欠損も0件とは区別し、全国全対象駅の計算が完了したことを確認する。
- 複数の距離・駅統合ルールでSS/Sと身近な駅がどう変わるかを測り、調査済み数値として詳細に掲載する。

## 画面と配信

- 通常のTier表を一枚の画面で提供し、全対象駅をデータに含める。9,000枚超を一度にDOMへ置かず、スクロールに応じた描画・絞り込みを使う。
- 「全国全駅」と「今の検索・地域・路線」の件数を明示。初期表示を上位駅だけに制限して全駅と呼ばない。
- 初期は自作の駅記号＋駅名を推奨。全駅写真は入手・出典・利用条件・欠損の整備が別作業になる。
- 詳細は得点、割当登録件数、距離条件、全国Tier境界、参考内訳、注意。判定理由は集計値から定型文で生成でき、LLMは不要。
- 地形図に直接その座標を開くには、現行の地域パラメータだけでなく座標・ズーム指定を読む機能の追加が必要。地域全域リンクだけでは該当駅を開いたことにならない。
- 駅・集計済みJSONを静的配信。ブラウザで原POIを集計する必要はない。既存地図への追加機能か別アプリかは着手時に決める。

## 順序・完了の基準

1. 東京の都市部・郊外で駅IDと路線所属を整備し、集計の試作。
2. 最近傍／固定円、距離上限、乗換駅の扱いでTierの安定性を比較。式と境界を確定。
3. 日本全国を集計。駅全件の一意ID・路線所属・処理完了、POIの割当／距離外／保留の件数一致を検証。
4. Tier表、検索、複数路線フィルタ、詳細、地形図への座標リンク、モバイル表示を実装。
5. 集計ルール・登録偏り・直線距離の限界・データ時点を記事と説明にまとめる。

計算量と表示性能は未計測。全世界地形の再生成は不要だが、全駅集計は新規作業。現時点でTier判定済みの全駅データやTier画面はない。
