- 1600×900 PNG。駅・密度・Tierをカバーの都合で改変せず、対応する峰がない駅は未判定として残す。

- 再生成はPillowがあるWindows環境で`python scripts/make_station_tier_covers.py`。文字・枠・出典の欠けを目視し、metadataの件数を確認。
